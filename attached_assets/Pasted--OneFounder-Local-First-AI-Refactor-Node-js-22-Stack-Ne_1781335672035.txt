# OneFounder – Local-First AI Refactor (Node.js 22)

### Stack: Next.js 14 · Node.js 22 LTS · Vercel · GitHub · Ollama · Neon PostgreSQL · Prisma

## Goal

Refactor OneFounder into a fully local-first AI platform with zero AI API costs.

Requirements:

* Remove OpenAI
* Remove Anthropic/Claude
* Remove Gemini
* Remove DeepSeek API
* Remove OpenRouter
* Remove Groq
* Remove all cloud AI providers
* Remove all cloud LLM routing
* Remove all paid inference services

Only Ollama remains.

Users provide their own compute resources.

All AI processing happens on the user's machine.

Monthly AI cost target:

₹0
